# Subjects

Bases views that cut across projects by **theme** (what the note is ABOUT). These provide cross-project navigation — notes live in `Daily/` or `Notes/<project>/`, not here.

Each file here is a Bases view that queries all notes linking to it via the `subjects` frontmatter property.

**Rules:**
- These are navigation views, NOT storage — notes do not live here
- Subjects cut across all categories
- A note can have multiple subjects
- Do not create new subjects without user approval
