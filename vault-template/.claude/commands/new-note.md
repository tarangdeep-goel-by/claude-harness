# /new-note — Create a New Note

Create a new note with the correct template.

Ask for (skip what's already provided in the user's message):
1. **What type of note?** (PRD, Meeting Note, 1:1, Decision, Customer Feedback, Research, Retrospective, Sprint Note, OKR, Feature Request, Competitive Analysis, Launch Plan)
2. **Title**
3. **Subjects** — which themes does this relate to?

Then:
1. Create the note in `Notes/` using the matching template from `System/templates/`
2. Fill in the title, categories, subjects, created date
3. Set appropriate initial status
4. Open the note for editing
